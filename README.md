# Anime World / Elsewhere corner packs

Public runtime content for Anime World / Elsewhere. Large assets live in GitHub Releases; catalog.json is the current discovery feed.

Corners 01–10 are Free. Corners 11 onward require Pro inside the app. Files are public by the owner's decision; the label is not server-side URL protection. This repository contains no app binary, credentials, or purchase receipts.

Content has SHA-256 and byte-size metadata. A content publication is not an App Store or Google Play app release.
